Processing pipeline

1 Ticket Analysis
→
2 Classify + Severity
→
3 KB Retrieval (TF-IDF)
→
4 Context Augmentation
→
5 Cited Resolution

Category and severity come from two TF-IDF + Logistic Regression models trained on real ticket data (Milestone 1). The resolution comes from a Retrieval-Augmented Generation pipeline (Milestone 2): the ticket text is matched against a knowledge base using TF-IDF + cosine similarity, and the response is built only from the retrieved articles — every step cites its source. No external AI API is called; everything runs on this server.
